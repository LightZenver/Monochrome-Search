# Changelog

Все заметные изменения описываются здесь. Формат основан на Keep a Changelog.

## [1.0.0] — 2026-11-09

### Добавлено
- Каркас UWP-приложения Monochrome (min 10.0.10240 / Windows 10 Mobile).
- Стартовый экран в монохромном стиле прототипа: логотип, поиск, ярлыки сайтов.
- Страница просмотра: адресная строка, WebView, кнопки назад/вперёд/дом, прогресс.
- Хранилище состояния (история, закладки, ярлыки, настройки) в LocalSettings.
- Маршрутизация навигации через Monochrome Gateway (пока выключена по умолчанию).
- CI: ночная сборка `.appx` (ARM) + релиз по тегам.
